# 🛡️ Security Policy

## 🛡️ Our Commitment
We take security seriously at **FluxPort 2.0**. Our team is committed to providing a secure API Gateway and collaboration suite for the developer community.

## 📦 Supported Versions
Use the latest stable releases of **FluxPort** to ensure you have the latest security patches.

| Version | Supported |
| :--- | :--- |
| **2.0.x** | ✅ Yes |
| **1.0.x** | ❌ No |

---

## ⚡ Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have found a security vulnerability, please report it to our security team privately. This allows us to resolve the issue before it's publicly disclosed, protecting all FluxPort users.

### 📧 How to report
- Email us at: [priyanshu@fluxport.org](mailto:priyanshu@fluxport.org)
- Provide a detailed description of the vulnerability.
- Include steps to reproduce the issue (PoC).
- If possible, include potential mitigation or a fix.

### 🕰️ What to expect
- We will acknowledge your report within **48 hours**.
- We will provide a preliminary evaluation within **5 business days**.
- We will handle all reports with high priority and keep you updated on the progress.

---

## 🏗️ Disclosure Policy
Once the vulnerability is confirmed and a patch is released, we will:
1. Release a security advisory.
2. Credit the researcher for their responsible disclosure (if desired).

Thank you for helping us keep **FluxPort** secure! 🤝
